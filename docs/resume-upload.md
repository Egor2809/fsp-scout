# Загрузка резюме

POST /api/v1/me/resume принимает multipart-поле file с PDF до 5 МиБ.
Проверяются роль candidate, собственный профиль, согласие personal_data,
MIME application/pdf и начальная сигнатура %PDF-. Поля не сохраняются автоматически.
Файл обрабатывается в памяти и передаётся отдельному Python-процессу через stdin;
на диск резюме не записывается. Исходное имя очищается от управляющих символов
и разделителей путей, ограничено 255 символами.

Для извлечения нужен Python с backend/requirements.txt; PYTHON_BIN задаёт путь
к интерпретатору (по умолчанию python). Скрипт scripts/extract-resume.py должен
присутствовать рядом с src/dist в поставке. Ограничения: 50 страниц,
100000 символов текста, 10 секунд на процесс, без зашифрованных PDF.
Python-процесс пока не имеет отдельного системного лимита памяти и сетевой
изоляции: для эксплуатации нужен контейнер с ограничениями.
Одновременно допускаются два процесса извлечения на экземпляр API; перегрузка
возвращает 429 rate_limited. Разрешение освобождается при завершении процесса,
а не при истечении тайм-аута. Это ещё не ограничивает память входящих multipart-загрузок.
Текущий тайм-аут и лимит вывода не заменяют ограничения памяти парсера.

Из текста извлекаются email, российский телефон, явно указанный Telegram,
город по словарю и навыки по справочнику. Остальные поля остаются пустыми.
Confidence — явно обозначенные эвристики, не измеренные вероятности.
Для сканов требуется дальнейшее подключение OCR. История работы и имя пока
не распознаются. Таким образом, полноценное распознавание резюме ещё не готово.

50 модульных тестов проходят, в том числе ограничение параллелизма, извлечение реальных текстовых фактов
и предупреждение для отсутствующего текстового слоя. Нагрузочные проверки
разбора резюме не проводились.
