# Вопросы с выбором ответа

Текущая версия v6: [assessment-canaries.md](assessment-canaries.md). Устойчивость choice-банка: [assessment-choice-resilience.md](assessment-choice-resilience.md). Ниже сохранён отчёт о первоначальном добавлении банка v4.

Версия банка: `expert-bank-20261010-v4`. Добавлены 70 семейств: по 9 single_choice и 1 multiple_choice для каждой из семи специализаций. Данные новых семейств находятся в `backend/src/assessment/choice-bank.ts`, подключение и выдача — в `live-bank.ts`.

Экземпляр параметризуется числовым контекстом. Порядок вариантов перемешивается алгоритмом Fisher–Yates от seed. После перемешивания публичные ID назначаются заново по позиции: серверный ID правильного ответа не выдаётся кандидату. Правильные ID сохраняются только в `expectedAnswer`.

Сложность распределена от −1.8 до +1.8. Это экспертные начальные оценки, не результаты эмпирической калибровки. Числовая подстановка и перемешивание не защищают от запоминания концептуального ответа; устойчивость к сливу требуется измерять отдельно.

## Проверки

- `npm test` из корня: 97/97 серверных тестов.
- В `backend/test/live-bank.test.ts` проверяются 200 seed каждого choice-семейства: уникальность вариантов, допустимость ключа, воспроизводимость, изменение позиции правильного ответа, разнообразие условий, полная проверка multiple_choice и отсутствие приватных ключей в публичном объекте.
- Отдельная строгая проверка типов модулей `live-bank.ts` и `choice-bank.ts` прошла локальным TypeScript 6.0.3.
- В `frontend/src/pages/candidate/TestRun.test.tsx` добавлены проверки выбора, снятия выбора, сброса при переходе к новому экземпляру и передачи `option_ids` в API-hook. Эти тесты пока не запускались: зависимости frontend отсутствуют.
- Полная проверка типов backend, frontend typecheck, Vitest и lint заблокированы отсутствием npm-зависимостей. Push не выполнялся.

Контракт не менялся: оба формата уже описаны в API. Отчёт валидации и файлы подбора не изменялись; второй участник должен пересчитать отчёт с новым банком.
