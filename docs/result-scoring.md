# Расчёт результата теста

Чистая функция scoreOutcome использует EAP-постериор 2PL и явную версионированную
политику порогов junior/middle/senior/lead. Пороги обязаны строго возрастать;
порог вероятности допускается от 0.7 до 1 (не включая 1). Без ответов расчёт
отклоняется. passed_confident означает достижение порога следующего грейда,
но лишь предлагает отдельную попытку: грейд без соответствующего теста не назначается.
Для lead следующего грейда нет, passed_confident не возвращается.

Политика из тестов является исключительно тестовой фикстурой. Производственные
пороги ещё нужно получить экспертной процедурой и проверить на пилоте;
автоматически применять тестовую фикстуру к профилям нельзя.

empiricalPercentile считает средний ранг при равных theta по независимой
нормативной выборке, исключая самого кандидата. По умолчанию требуется минимум
30 других кандидатов; иначе возвращается null. Дубликаты кандидатов отклоняются.
Вызывающий код должен выбрать одну категорию и версию калибровки, а также одну
оценку на кандидата. Результат округляется и ограничивается 1..99 согласно API.
Синтетические данные не должны использоваться как реальные нормы.

GET /tests/:id/result добавлен для чтения уже сохранённого результата своей
завершённой сессии. Проверяются схема результата и совпадение test_id.
Незавершённая сессия возвращает конфликт; чужой тест не найден.
Пока нет транзакционного finish, который создаёт такой результат: чтение
не подтверждает готовность полного сценария тестирования.

Проходят 54 модульных теста. Добавлены проверки исходов по порогам,
следующего грейда, отсутствия данных, перцентиля, равных theta и дубликатов.
Подключение к finish, практика, флаги, подтверждение навыков, нормативная
выборка и HTTP-проверки остаются в работе.
