# Подтверждение навыков тестом

Правило `independent-families-v1`: успешный результат, разрешённое подтверждение категории, минимум три разных семейства адаптивных заданий с явной привязкой к навыку справочника и минимум 80% правильных ответов. Это продуктовое правило достаточности свидетельств, а не эмпирическая калибровка владения навыком. Присваивается только уровень basic; confident/advanced автоматически не выводятся из общего грейда.

Повторные варианты одного семейства не увеличивают число свидетельств. Противоречивые ответы внутри семейства учитываются как ошибка. Неоценённые, неотвеченные, практические и уточняющие задания не используются. Метаданные берутся только при точном совпадении сохранённой версии банка с доступным LIVE_BANK_VERSION. Неизвестные навыки не подтверждаются.

Версия правила сохраняется в policy новой сессии при старте. Сессии без этой версии или с другой версией не получают новых подтверждений по текущему правилу. Исторические результаты не пересчитываются. Изменение порогов требует новой версии и отдельного обработчика старой версии либо отказа от новых подтверждений для неё.

Результат сохраняет confirmed_skills; профиль получает эти навыки в той же транзакции. Подтверждения ФСП и регулярными заданиями сохраняются. При смене категории старые подтверждения источника test удаляются, чтобы не переносить их автоматически между специализациями. При неудачной попытке профиль не меняется. Версия правила и идентификаторы навыков фиксируются в аудите.

Текущий небольшой банк может не обеспечить три независимых семейства на конкретный навык: в этом случае список остаётся пустым. Расширение банка и проверка качества правила на данных остаются обязательными. Модульный тест проверяет пороги, независимость семейств и исключение непригодных свидетельств; транзакционный сценарий ещё требует PostgreSQL и собранного приложения.
