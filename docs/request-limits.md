# Размеры запросов

POST /api/v1/eval/rank принимает JSON до 256 MiB: контракт разрешает 2000 резюме по 20000 символов и 100 вакансий по 8000; JSON-экранирование может занимать шесть байт на символ. Расширенный парсер применяется только к этому маршруту с application/json, включая query string и завершающий slash. Другие JSON и urlencoded запросы ограничены 100 KiB; multipart резюме отдельно ограничен 5 MiB.

Переполнение body-parser преобразуется в 413 application/problem+json, синтаксическая ошибка JSON — в 400. Содержимое запроса в ошибку не включается. Raw body сохранён для проверки подписи webhook.

75 модульных тестов проходят, включая выбор парсера. Реальная сборка NestJS, HTTP-ошибки и обработка предельного пакета ещё не проверены. Большой JSON полностью буферизуется до AuthGuard, включая rawBody; перед production нужны замеры пикового RSS, ограничение параллелизма/скорости на входе и согласованный лимит reverse proxy. Синтетический ranking-load с короткими резюме не подтверждает ёмкость предельного HTTP-запроса.

API настройки сверено с исходным интерфейсом NestJS 11.1.6: https://github.com/nestjs/nest/blob/v11.1.6/packages/platform-express/interfaces/nest-express-application.interface.ts
