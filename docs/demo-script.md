# Сценарий видео: 6 минут

Видео записывается на проверенном реальном стенде. Если для части показа
используются моки, это явно произносится и показывается на экране.

| Время | Экран | Что показать |
|---|---|---|
| 0:00–0:35 | Главная и вход | Обратный найм, роли, анонимный профиль, вход кандидата |
| 0:35–1:45 | Тест | Выбор категории, варианты заданий, адаптация, практика с кодом |
| 1:45–2:15 | Результат | Категория, перцентиль, точность и ограничения подтверждения |
| 2:15–3:20 | Кабинет работодателя | Потребность, фильтры, вклад факторов, кандидат на грейд ниже |
| 3:20–4:20 | Приглашение | Обязательная вилка, согласие кандидата, раскрытие контактов компании |
| 4:20–5:10 | /evaluate | Собственные резюме, реальное ранжирование, объяснение вкладов |
| 5:10–5:45 | Отчёт | Выполненные тесты, синтетика и её ограничения, состояние стенда |
| 5:45–6:00 | Завершение | Репозиторий и материалы сдачи |

Перед записью: убедиться в готовности Keycloak, API, очереди и Piston;
проверить тестовый банк и политику подтверждения; подготовить обезличенные
аккаунты кандидата и работодателя. Не показывать `.env`, токены и реальные
контакты. Не выдавать диагностический/мок-результат за подтверждённую категорию.
Сам видеофайл ещё не записан.
