# Завершение теста

POST /tests/:id/finish добавлен в исходниках. Транзакция блокирует Candidate,
затем TestSession. Чужая сессия не найдена. Повтор завершённой сессии возвращает
сохранённый результат после проверки схемы и test_id. Истечение срока фиксируется
до возврата конфликта; срок повторно проверяется перед записью результата.

Досрочное завершение разрешено согласно контракту. Уже выданное неотвеченное
задание атомарно сохраняется как skipped=true/correct=false; существующие ответы
не переписываются. Невыданные экземпляры не создаются фиктивно. Если не выполнены
минимум/остановка CAT, покрытие компетенций или обязательная практика, тест
завершается с failed и low confidence из-за недостатка доказательств; прежняя
категория сохраняется. Нулевая или короткая сессия не подтверждает грейд по prior.
Ожидание оценки уже принятого ответа возвращает конфликт, а не заменяется пропуском.
Для полного прохождения проверяются минимум CAT, достижение точности либо максимума,
покрытие обязательных компетенций и число завершённых практических заданий.
Результат содержит
EAP, SE, реальные баллы компетенций и траекторию по последовательным ответам.
Флаги вставки/фокуса информационные. Без реальных моделей времени fast_correct
не вычисляется. Автоматический провал по событиям браузера не применяется.

ASSESSMENT_GRADE_POLICY — JSON с version, cuts (junior/middle/senior/lead),
passProbability. Start проверяет и сохраняет эту политику в сессии. Значений
по умолчанию нет: нужны экспертные пороги и проверка на пилоте. Старые сессии
без политики порогов не могут завершиться с выдуманными порогами.
Для Compose переменную ещё нужно передать явно после утверждения политики.

Смена категории проверяет глобальные 90 дней под блокировкой. Провал сохраняет
прежнюю категорию; диагностическая исключительная попытка не обходит ограничение.
Смена категории создаёт GradeHistory; повтор finish не создаёт вторую запись.
Рекомендация следующего теста использует существующий расчёт eligibility.

Нормативная выборка подключена в исходниках: завершённые успешные тесты той же
специализации и грейда, с совпадающими bankVersion и политикой порогов.
Сравниваются не только название версии, но и сами cut/passProbability.
Сам кандидат, будущие результаты и диагностические попытки без подтверждения
целевой категории исключаются. Берётся последний подходящий результат каждого
другого кандидата. При минимум 30 наблюдениях считается эмпирический перцентиль
и сохраняется standing; иначе перцентиль null. При смене категории без норм
профиль пока скрыт, при повторе прежней категории старый standing сохраняется.
Размер выборки и версии фиксируются в аудите, личности участников туда не пишутся.
Новые навыки пока не подтверждаются (confirmed_skills=[]):
нужен критерий достаточности независимых заданий на навык.

Это промежуточная реализация. Start по-прежнему блокируется недостаточным банком,
выдача практики, /run, очередь скрытой оценки и блок C есть в исходниках,
но реальная цепочка ещё не проверена. Новые сессии требуют practiceTotal=1
и approachTotal=1, старые без обязательных блоков не могут
подтвердить новую категорию. Нужны интеграционные
проверки гонок/сроков/повторов, Prisma-сборка, нормирование и полный frontend-сценарий.
63 модульных теста проходят; они не подтверждают работу транзакции PostgreSQL.
Миграция 20261010008000_normative_cohort добавляет индекс выборки, но ещё не применена.
Запрос пока загружает подходящую историю в память; для больших когорт нужны
агрегированные версионированные нормы, обновление ранних профилей после накопления
выборки, проверка репрезентативности и нагрузочное измерение. Реального пилота нет.

integration/finish.test.mjs проверяет конкурентный досрочный finish, повтор результата
и сохранение прежней категории/истории. Нужны TEST_CANDIDATE_TOKEN и
TEST_EARLY_FINISH_TEST_ID: собственная свежая пустая активная сессия с сохранёнными
gradeCuts и adaptive_min >= 2 в одноразовой тестовой базе. Синтаксис проверен;
без зависимостей и работающей инфраструктуры этот HTTP-тест пока не выполнен.
