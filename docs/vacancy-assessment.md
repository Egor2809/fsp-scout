# Тест по вакансии

Start с vacancy_id читает опубликованную вакансию, проверяет специализацию/заявленный грейд и сохраняет снимок vacancyBlueprint в policy. Непокрытые требования и недостаточная ёмкость банка дают 409. Изменение вакансии после старта не меняет сохранённую политику и веса текущего теста.

Адаптивный банк ограничен компетенциями blueprint. Доли компетенций влияют на выдачу: после первичного покрытия выбирается наибольший дефицит относительно целевой доли, затем информационный top-K и случайный выбор. Экспозиция и запрет повторения применяются раньше выбора; веса их не обходят. Проверен пример 75/25: за 12 ответов распределение 9/3. Веса включены в подпись нормативной популяции, чтобы не смешивать разные планы измерения.

82 модульных теста проходят. Источник start больше не содержит безусловного отказа для vacancy_id. Однако нынешний адаптивный банк всё ещё недостаточен для выбранной политики — рабочий старт этим изменением не доказан. Практика пока общая для специализации, без привязки содержания к конкретной вакансии; требуется завершить соответствующие практические задания. SQL/HTTP и сравнение планируемого/фактического покрытия ещё не проверены.
