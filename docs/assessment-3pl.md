# Оценка способности с учётом угадывания

числовые задания имеют c = 0, single_choice — 1 / число вариантов, multiple_choice — 0,05. Это экспертные параметры без эмпирической калибровки. При L = logistic(a(θ − b)) вероятность ответа P = c + (1 − c)L, информация Фишера — a²(1 − c)L²(1 − L) / P. EAP использует прежний нормальный prior N(0,1) и логарифмическое правдоподобие. При c = 0 сохраняется 2PL.

`irt_c` сохраняется в закрытом JSON задания. Выбор следующего вопроса, завершение, результат и траектория используют согласованные параметры. Сохранённый c имеет приоритет. Старые записи с JSON без `irt_c` сохраняют c = 0 для воспроизводимости истории. Объекты без JSON-параметров, включая eval, получают c из семейства. CAT восстанавливает его по familyId, а для прежнего формата состояния — по порядку выданных семейств. Реальный API передаёт familyId и сохранённый c.

Новые полные тесты имеют максимум 14 адаптивных вопросов вместо 12, выбор из трёх наиболее информативных вместо пяти. Минимум 8, целевая SE 0,4, потолок экспозиции 0,4 и 40 минут сохранены. Экспресс остаётся на 5–6 вопросах. Начатые сессии сохраняют прежнюю политику; интерфейс получает максимум из API. Банк v5 достаточен для нового максимума во всех специализациях.
