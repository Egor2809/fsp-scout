# Раунд 2: устойчивость заданий с выбором

Ниже результаты пункта 1 до перехода на 3PL. Текущие метрики: [assessment-3pl.md](assessment-3pl.md).

Банк `expert-bank-20261010-v5` содержит прежние 230 семейств. У всех 70 choice-семейств теперь пять ситуаций: исходная и четыре новые, всего 350 формулировок. Пулы находятся в `choice-pools.ts`, генератор — в `choice-bank.ts`. ID, навыки, специализации, компетенции и экспертные a/b сохранены; версия choice-шаблонов повышена до 2.

Seed выбирает ситуацию и количественный контекст, затем существующий механизм детерминированно перемешивает варианты и заменяет приватные ID публичными. В задачах на границы, вывод event loop и изменение переменной числа подставляются также в ответы. В концептуальных вопросах правильное решение меняется между ситуациями. Пулы создаются один раз. При вычитке устранены семантически одинаковые варианты READ COMMITTED и уточнены условия сохранения Android/Compose-состояния и сигнала остановки Pod.

## Проверки и ограничения среды

- `cd backend; npm test` — 111/111. Для каждого choice-семейства проверены 200 seed, пять ситуаций, минимум четыре разных ключа, детерминированность, уникальность вариантов и отсутствие ключей в публичном объекте. В каждом новом пуле также проверены четыре разных ключа до подстановки чисел.
- `choice-content.test.ts` независимо сверяет индекс с WHERE/ORDER BY, границы с открытостью интервала; отображаемый JavaScript для event loop и изменения переменной исполняется в Node VM и сравнивается с ключом.
- `choice-leak.test.ts` проверяет ограничения 30% на каждое choice-семейство и 35% на весь банк.

Повторная валидация из `backend` в PowerShell:

```powershell
New-Item -ItemType Directory -Force .npm-cache | Out-Null
$env:EVAL_OUT = Join-Path (Get-Location) '.npm-cache/round2-after.json'
npm run eval
Remove-Item Env:EVAL_OUT
```

Эта метрика проверяет точное совпадение вопроса с дампом или повтор наиболее частого текстового ключа. Она не доказывает защиту от изучения всех ситуаций или решения по смыслу. Некоторые числовые семейства сохраняют малое пространство ответов; они не менялись. Сложности остаются экспертными, без новой калибровки на людях. Перед обновлением стенда нужно завершить старые сессии: сервер выдаёт задания только для актуальной версии банка.
