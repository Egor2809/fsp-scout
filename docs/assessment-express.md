# Экспресс-тест для жюри

`ASSESSMENT_EXPRESS=true` включает демонстрационный режим для новых тестов: 5–6 адаптивных вопросов, лимит 600 секунд, без практики и уточняющего вопроса. При отсутствии переменной используется полный режим. В `infra/.env.example` экспресс включён для демонстрации.

Политика и признак режима сохраняются в сессии. Изменение переменной не меняет уже начатый тест. Ответы оцениваются обычным механизмом; результат показывает theta, SE и компетенции, но не присваивает категорию, перцентиль и подтверждённые навыки. Попытка не расходует исключение пересдачи и не блокирует последующий полный тест. Требования к согласию, опросу и отсутствию другой активной сессии сохраняются.

На лендинге реального API появляется кнопка «Экспресс-тест для жюри (5 минут)». Она открывает вход `jury1-candidate@demo.ru`; после входа нужно пройти согласия, опрос и выбрать грейд. Пароль демонстрационных аккаунтов указан на лендинге. Пометки доступны в результате, истории тестов и профиле кандидата. Пять минут — ориентир прохождения, не измеренная длительность.

Compose передаёт настройку серверу и сборке интерфейса. После изменения настройки нужно пересобрать `web`:

```powershell
docker compose --env-file infra/.env -f infra/compose.yaml up --build -d api web
```

Для полного тестирования задайте `ASSESSMENT_EXPRESS=false` и пересоберите сервисы. При отдельном запуске frontend задайте соответствующее `VITE_ASSESSMENT_EXPRESS`; кнопка появляется только при `VITE_API_MOCK=false`. Режим не имитируется MSW.

## Проверка

- `npm test` — 100/100. Новые тесты проверяют выключение по умолчанию, отдельный снимок политики, запрет подтверждения категории, исключение демонстрационных попыток из истории пересдач и завершение за 5–6 вопросов на всех специализациях (140 прогонов реального банка).
- `npm run check:contract` — успешно. В TestSession, TestSessionSummary и TestResult добавлен необязательный boolean `express`; старые записи без поля остаются совместимыми.
- Отдельная строгая проверка типов `session-state.ts` и `completion.ts`, проверка синтаксиса изменённых контроллеров и страниц и `docker compose ... config --quiet` прошли.
- `npm run generate:api` заблокирован: Orval не установлен. Изменения моделей и Zod-снимков синхронизированы адресно; полную генерацию необходимо повторить после установки зависимостей. Full build, Vitest, lint и браузерная проверка пока не выполнены по той же причине.

База данных и Prisma-схема не менялись. Push не выполнен до прохождения всех обязательных проверок. Код подбора и отчёт валидации не изменялись.
