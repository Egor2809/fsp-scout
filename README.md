# Скаут — обратный найм по подтверждённым навыкам

Проект команды Egor2809 для специального трека ФСП. Кандидат проходит адаптивное
тестирование, публикует анонимную карточку и получает приглашения с зарплатной
вилкой. Контакты раскрываются конкретной компании после согласия кандидата.
Это самостоятельный проект; совпадение названия с другими решениями трека
не означает общий код или общую команду.

## Запуск

Требуются Docker Engine с Compose и доступ к реестрам контейнеров/npm.

```powershell
Copy-Item infra/.env.example infra/.env
# Замените POSTGRES_PASSWORD, KEYCLOAK_ADMIN_PASSWORD и FSP_WEBHOOK_SECRET.
docker compose --env-file infra/.env -f infra/compose.yaml config --quiet
docker compose --env-file infra/.env -f infra/compose.yaml up --build -d
```

Интерфейс: http://localhost:5173, API: http://localhost:8000/api/v1,
Keycloak: http://localhost:8080, тестовая почта Mailpit: http://localhost:8025.
Контейнер frontend использует реальный API и OIDC. Демо-персоны из моков
не являются созданными учётными записями Keycloak.

Подробности: [локальный запуск](docs/local-deployment.md),
[публичный HTTPS-стенд](docs/public-deployment.md),
[техническая документация](docs/technical-guide.md).

## Проверки

Node.js 24 позволяет запустить backend-тесты и синтетический эксперимент
без установки npm-зависимостей:

```powershell
npm test
npm run check:contract
npm run test:evaluate
npm run eval
```

Для сборки установите зависимости в `backend` и `frontend`, выполните
`npm --prefix backend run prisma:generate`, затем `npm run typecheck`.
GitHub Actions проверяет backend, сборку frontend, тесты, снимок контракта
и синтетический эксперимент. Результат эксперимента сохраняется как артефакт CI.

## Что проверено

На 10.10.2026 локально проходят 87 backend-тестов и проверка снимков контракта.
Compose проходит проверку конфигурации. Это не подтверждает запуск контейнеров
или прохождение всего сценария через браузер.

Синтетика: 200 профилей, seed 20261009, RMSE theta ≈ 0,408,
корреляция test–retest ≈ 0,846, точный грейд 68%. Ответы генерируются
той же моделью 2PL, которую использует оцениватель; эти числа не являются
проверкой на реальных кандидатах или выполнением цели 2.3 плана.
Полный отчёт: [eval/synthetic-report.json](eval/synthetic-report.json).

## Подбор

Поиск сохраняет обязательные навыки, специализацию, согласие на публикацию,
приватность компании и условия работы как строгие ограничения. Кандидаты
на один грейд ниже выбранного показываются со штрафом 8 баллов и отдельной
пометкой в карточке. Их подтверждённая категория не меняется.
Достижение доли скрытых релевантных ≤30% требует независимой разметки.

`/evaluate` после входа работодателя позволяет ранжировать собственные резюме
и видеть вклад каждого фактора. Используется реальный `/api/v1/eval/rank`;
мок-режим страницы отключён. Необязательная полная разметка 0–4 позволяет
рассчитать nDCG@10, Recall@10 и RR@10; без разметки метрики не показываются.

## История разработки

Backend разрабатывался отдельно от frontend; в предоставленной локальной копии
он находится вместе с интерфейсом в ветке `my-feature` (коммит `0afb34b`).
Проверяемая история этой копии содержит один коммит, поэтому дату и факт
последующего слияния в `main` по ней установить нельзя.
